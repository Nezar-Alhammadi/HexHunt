# Security policy

HexHunt processes security-testing targets and model-generated actions. Do not include live credentials, private target data, or sensitive findings in public issues.

For vulnerabilities in HexHunt itself, use GitHub's private vulnerability reporting or a private security advisory for this repository. Include only the minimum reproduction information required and redact all third-party data.

HexHunt must be used only against systems owned by the operator or covered by explicit authorization.
